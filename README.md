# 🛒 Amazon Clone

A responsive Amazon homepage clone built using **HTML** and **CSS**. This project recreates the basic layout and design of Amazon's website to practice frontend development skills.

## 🚀 Features

- Responsive navigation bar
- Search bar
- Hero section
- Product categories
- Product cards
- Footer with multiple sections
- Clean and responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📁 Project Structure

```
Amazon-Clone/
│── index.html
│── style.css
│── images/
│── README.md
```

## 💻 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
